# 录屏前初始化

本 Skill 只负责录屏开始前的初始化：确认录屏工作目录，并创建用户消息操作日志 Hook。录屏前不要读取 `录屏后.md`，避免影响录制期间的操作风格。

## 录屏目录

先确认录屏工作目录。默认使用当前工作区下的 `./录屏产物/`；若用户指定其他目录，以用户指定为准。下文统一用 `<录屏工作目录>` 表示，不要写入作者本机绝对路径。

创建 Hook 前必须把 `<录屏工作目录>` 替换为实际路径，不要保留尖括号占位符。若使用相对路径，必须按当前工作区解析，并在回复中告诉用户实际目录。

## Hook 创建

创建以下 Hook，完成后告知用户“Hook 已创建，随时可以开始录屏”，并说明日志会写入 `<录屏工作目录>/recording-log.txt`。

```
名称：录屏操作日志
触发事件：promptSubmit
动作类型：runCommand
命令：mkdir -p "<录屏工作目录>" && printf '[%s] %s\n' "$(TZ='Asia/Shanghai' date '+%Y-%m-%d %H:%M:%S')" "$KIRO_USER_MESSAGE" >> "<录屏工作目录>/recording-log.txt"
```

Hook 创建后，整个录屏期间每条用户消息都会自动记录北京时间戳，无需手动操作。

若当前环境不支持 Hook、`promptSubmit` 或 `$KIRO_USER_MESSAGE`，不要编造已创建成功。应明确告诉用户“当前环境无法自动记录用户消息”，并要求用户在录屏结束时手动提供起止时间和关键操作摘要。
