# File Storage (Volume)

A Volume is an object in Singdata Lakehouse that represents an object storage location, used to store and manage files in various formats.

| Type | Description | Reference |
|------|------|---------|
| Internal Volume | Lakehouse-managed internal storage, suitable for temporary files and user uploads | [Internal Volume](internal_volume.md) |
| External Volume | Mount an existing object storage location (OSS/COS/S3) to access external data | [External Volume](external_volume.md) |

For detailed Volume SQL commands, see [Volume SQL Reference](volume-introduction.md).
