# Studio: Integrated Web Development and Management Tool for Lakehouse

Lakehouse Studio is a web user interface provided by Lakehouse, an integrated set of development and management tools designed to offer users an intuitive and convenient operational experience. By logging in through a browser and accessing the Lakehouse service instance, users can easily operate and utilize the various features provided by Lakehouse on the Web interface, which is more convenient and user-friendly compared to SQL connections and CLI command-line tools.

^

## Main Features

### Data Synchronization

Users can configure data sources through a visual interface to achieve automatic data synchronization and integration.![](.topwrite/assets/image_1758622264912.png)

### Task Development and Orchestration

Users can write, debug, and schedule data processing tasks in the IDE, automating the data processing workflow.

![](.topwrite/assets/image_1758622436565.png)

### Task Operations and Maintenance

Users can perform operations such as starting, stopping, pausing, and resuming tasks to ensure the stable operation of the data processing workflow.

![](.topwrite/assets/image_1758622571370.png)

### Task Monitoring and Alerts

Users can view the real-time status of tasks and receive real-time notifications of exceptions through alert rules.

![](.topwrite/assets/image_1758622620633.png)

### Data Quality Management

Users can assess, clean, and repair data to ensure its accuracy and consistency.

![](.topwrite/assets/image_1758622726956.png)

### Data Catalog Management

Users can categorize and tag data for easy retrieval and use.

![](.topwrite/assets/image_1758622786514.png)

### Security Management

Users can configure access permissions and audit logs to ensure the security of data and tasks.

![](.topwrite/assets/image_1758622971965.png)

### Computing Cluster and Job Management

Users can manage and monitor computing cluster resources to optimize the execution efficiency of jobs.

![](.topwrite/assets/image_1758623011205.png)

### Workspace Management

Users can create and manage multiple workspaces to achieve isolation and collaboration between projects and teams.

![](.topwrite/assets/image_1758623089985.png)
