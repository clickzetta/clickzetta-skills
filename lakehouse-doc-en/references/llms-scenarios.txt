# Singdata Lakehouse — Use Cases

- [Industry Solutions Overview](https://singdata.com/documents/solutions/usage_scenarios_overview): An index of Singdata Lakehouse industry solutions spanning manufacturing, retail, mining, and autonomous driving, mapping each to its core dataset and key capabilities like Dynamic Table, AI Functions, PIPE, and Volume.
- [Autonomous Driving Full-Loop Data Platform Solution](https://singdata.com/documents/solutions/autonomous-driving-full-loop): Covers road-test camera/LiDAR/CAN data, telemetry, and annotation workflows for autonomous driving R&D, using Dynamic Table, Volume, AI_COMPLETE, and Table Stream to build a closed-loop data flywheel from collection to model iteration.
- [Smart Mine Safety Early Warning Solution](https://singdata.com/documents/solutions/smart-mine): Unifies sensor data from six coal/non-coal mine subsystems (ventilation, monitoring, transport) for cross-system correlation and predictive safety alerting, using AI_CLASSIFY, AI_COMPLETE, AI_EMBEDDING, Dynamic Table, and full-text/vector/hybrid search.
- [Manufacturing Part Defect AI Detection & Classification](https://singdata.com/documents/solutions/defect-detection-ai): Fuses AOI defect images, MES text descriptions, and SCADA process parameters from precision manufacturing lines into one pipeline, using AI_CLASSIFY, AI_EXTRACT, AI_COMPLETE, Dynamic Table, and OSS/S3 Volume for automated dual-channel defect detection.
- [Equipment Predictive Maintenance Solution](https://singdata.com/documents/solutions/predictive-maintenance): Processes real-time vibration, temperature, and pressure sensor streams from factory equipment (CNC machines, injection molders, reactors) using Dynamic Table, AI_COMPLETE with DeepSeek V3, and Bloomfilter Index for anomaly detection and AI maintenance recommendations.
- [Supply Chain Inventory Optimization](https://singdata.com/documents/solutions/supply-chain-inventory): Integrates WMS inventory snapshots, OMS demand, ERP replenishment cycles, and supplier lead-time data across manufacturing and retail, using Window Functions, Dynamic Table, MERGE INTO, and AI_EXTRACT for dynamic replenishment decisions.
- [Customer Complaint Intelligent Labeling](https://singdata.com/documents/solutions/complaint-labeling): Automates e-commerce and retail customer service ticket classification using Dynamic Table and AI_COMPLETE, replacing manual labeling with a real-time SQL pipeline achieving end-to-end latency under 5 minutes.
- [Product Review Sentiment Analysis](https://singdata.com/documents/solutions/product-review-sentiment): Consumes e-commerce Kafka review streams and applies AI_SENTIMENT and AI_COMPLETE within Dynamic Table and CREATE PIPE to deliver real-time sentiment classification and structured summary extraction without a separate AI inference service.
- [Email Customer Support Auto-Triage](https://singdata.com/documents/solutions/email-customer-support): Processes e-commerce and cross-border customer service emails using Dynamic Table, AI_COMPLETE, REGEXP_EXTRACT, and GET_JSON_OBJECT to combine intent classification, entity extraction, and reply drafting into a single AI call with under 10-minute latency.
- [User Behavior Funnel Analysis](https://singdata.com/documents/solutions/user-behavior-funnel): Aggregates multi-channel e-commerce and local services behavior event streams using Dynamic Table, MERGE INTO, COUNT DISTINCT, and Window Functions to compute per-channel funnel conversion rates with under 1-hour latency.
- [Industrial IoT Device Health Monitoring Data Warehouse Best Practices](https://singdata.com/documents/solutions/iot-device-health-monitoring-dw-best-practices): Builds a Bronze/Silver/Gold warehouse from 20 industrial devices and 100 sensor events using Kafka PIPE, Dynamic Table, Bloomfilter Index, Column Masking, and SQL UDF to produce device health scores and predictive maintenance alerts.
- [Gaming Operations Data Warehouse Best Practices](https://singdata.com/documents/solutions/gaming-operations-dw-best-practices): Simulates login, level, and payment events against a 15-game Steam catalog dataset, using Kafka PIPE, Dynamic Table, GROUP_BITMAP functions, LAG/LEAD window functions, and Bloomfilter Index to compute LTV segmentation, payment funnels, and retention matrices.
- [Build a Retail Chain Store Operations Data Warehouse](https://singdata.com/documents/solutions/retail-chain-pos-dw-best-practices): Uses the Kaggle Retail Data Warehouse 12-table dataset across 100 chain stores, combining MySQL CDC full-database mirror, Dynamic Table, store_id partitioning, Bloomfilter Index, External Schema (Hive), and Time Travel for SKU turnover and store ranking analysis.
- [Build a SaaS Multi-Tenant Operations Data Warehouse](https://singdata.com/documents/solutions/saas-operations-dw-best-practices): Uses the RavenStack SaaS dataset (500 tenants, 5,000 subscriptions/usage events, 600 churn records) with Kafka PIPE, Dynamic Table cascading refresh, SQL UDF health scoring, Column Masking, RBAC, and Semantic View to compute tenant health scores and churn warnings.
- [Build a Digital Marketing CDP: Cross-Channel User ID Unification Data Warehouse](https://singdata.com/documents/solutions/marketing-cdp-dw-best-practices): Uses the Online Retail II Kaggle dataset with MySQL CDC, Kafka ingestion, ID Mapping, MERGE INTO, External Function calls, and Dynamic Table RFM/BITMAP audience selection to build a unified OneID system for cross-channel marketing segments.
- [Graph-Driven Financial Fraud Gang Detection Data Warehouse Best Practices](https://singdata.com/documents/solutions/fraud-graph-detection-dw-best-practices): Models 20 accounts, 10 devices, 10 IPs, and 25 transaction edges as a graph using MERGE INTO, Dynamic Table, SQL UDF gang risk scoring, Bloomfilter Index, Inverted Index, and ZettaPark Python with NetworkX to detect fraud gangs and underground rings.
- [Build a Supply Chain and Logistics Tracking Data Warehouse](https://singdata.com/documents/solutions/supply-chain-logistics-dw-best-practices): Uses a Kaggle retail dataset (orders, inventory, logistics, suppliers) with PostgreSQL CDC, MySQL offline sync with warehouse/date partitioning, OSS PIPE, and Dynamic Table cascading refresh to monitor SKU turnover and shipment on-time rates.
- [Build a Real-Time Financial Risk Control Data Warehouse](https://singdata.com/documents/solutions/financial-risk-control-realtime-dw-best-practices): Uses the Kaggle Credit Card Transactions Fraud Detection dataset with Kafka PIPE, Dynamic Table sliding-window aggregation, SQL UDF risk scoring, Column Masking, and RBAC to produce millisecond real-time risk scores for every transaction.
- [Build a Healthcare Operations Data Warehouse](https://singdata.com/documents/solutions/healthcare-operations-dw-best-practices): Integrates HIS, EMR, and lab system data using California hospital Q1 2025 admission records via MySQL offline sync, Dynamic Table, Column Masking, RBAC access tiering, and Time Travel to produce department performance metrics and compliance audit trails.
