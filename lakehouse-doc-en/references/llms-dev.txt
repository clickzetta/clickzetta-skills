# Singdata Lakehouse — Development Manual

- [Java SDK](https://singdata.com/documents/java_sdk_guide): Overview of the clickzetta-java SDK providing JDBC queries, real-time streaming writes, and high-throughput Bulkload, with a contents table and comparison of the three write methods and their use cases.
- [Java SDK Summary](https://singdata.com/documents/java_reference/java-sdk-summary): An introduction to the clickzetta-java SDK providing the JDBC driver, real-time write, and bulk write capabilities, covering Maven setup, notes, and a JDBC usage example.
- [Java SDK Version History](https://singdata.com/documents/version-update): Java SDK update records listing recent versions and their changes, including vector type writes, COPY deprecation in favor of PUT, JSON and TIMESTAMP_NTZ support, with download links.
- [Initialize Client](https://singdata.com/documents/java_reference/client): Documents initializing ClickZettaClient in Java via JDBC URL or builder parameters (instance, service, username, vcluster, schema) for creating RowStreams and JDBC connections, plus closing the client.
- [Query Using JDBC](https://singdata.com/documents/java_reference/jdbc): JDBC usage guide for the clickzetta-java SDK, covering Maven dependency, connection string format and parameters, driver class, two connection-initialization methods, and query execution examples.
- [Real-time Data Ingestion](https://singdata.com/documents/java_reference/realtime-upload): Explains the principle of real-time writing to Lakehouse via the Java SDK, covering the ingestion service, hybrid tables, data commit, applicable scenarios, stream creation, and write options.
- [Bulkload Introduction](https://singdata.com/documents/bulkload-summary): Quick start for Lakehouse Bulkload, a high-throughput batch write SDK, explaining upload-to-object-storage principles, the bulkloadStream.close trigger, compute resources, shard optimization, and applicable versus unsuitable scenarios.
- [Bulkload Java SDK](https://singdata.com/documents/bulkloadv1-java-sdk): Guide to batch data upload using the deprecated BulkLoadV1 Java API, covering Maven dependencies, creating a BulkloadStream, partition options, APPEND/OVERWRITE modes, and writing simple and complex-type rows.
- [Python SDK (SQL Interface)](https://singdata.com/documents/python_sdk_guide): Overview of the clickzetta-connector Python SDK, covering its four integration methods (Database API, SQLAlchemy, Bulkload, and real-time writes) with a comparison of use cases and links to detailed references.
- [Python SDK Summary](https://singdata.com/documents/python_reference/python-sdk-summary): Overview of the Lakehouse Python SDK, describing the PEP-249-compliant clickzetta-connector with bulkload support and the clickzetta-sqlalchemy adapter, with connection parameters and usage examples for each.
- [Query Using Python Database API](https://singdata.com/documents/python_reference/connector): Documents the official clickzetta-connector Python SDK following PEP-249, covering installation, establishing connections, executing queries, parameter binding, batch insert, and asynchronous execution.
- [Python Connector Usage Examples](https://singdata.com/documents/python_reference/connector_examples): Provides runnable clickzetta-connector Python examples for common scenarios, covering establishing a connection, bulk inserting order data, and conditional querying with result processing.
- [Python Connector Advanced Usage](https://singdata.com/documents/python_reference/connector_advanced): Advanced features of the clickzetta-connector Python SDK, covering fetch_pandas for returning DataFrame results and arraysize for controlling the fetchmany batch size.
- [Query Using SQLAlchemy](https://singdata.com/documents/python_reference/sqlalchemy): A guide to the ClickZetta SQLAlchemy dialect adapter, covering installation, removing old dependencies, and quick-start examples for creating an engine and executing SQL queries via URL string.
- [Bulkload Python SDK](https://singdata.com/documents/bulkloadv1-python-sdk): A guide to batch data upload (BulkLoad) into Lakehouse using the Python clickzetta-connector SDK, covering installation, import principles, compute resources, shard optimization, and single-threaded writing.
- [Real-time Data Ingestion Python SDK](https://singdata.com/documents/python-igs): The Lakehouse Python SDK real-time write feature, covering installation, the write principle, applicable scenarios, notes, data type mappings, and creating a real-time data stream.
- [Python SDK Version History](https://singdata.com/documents/python-sdk-version-history): Changelog for the clickzetta-connector Python connector, listing version 0.8.54 (project management migration) and 0.8.51 (improved login error messages and get_job_profile API).
- [Python SQLAlchemy Version History](https://singdata.com/documents/python-sqlalchemy-version-history): A changelog documenting version history of the clickzetta-sqlalchemy package, listing release dates, installation commands, and changes for versions 0.8.53 and 0.8.55.
- [ZettaPark (DataFrame API)](https://singdata.com/documents/lakehousepython-zettapark): ZettaPark is the Python DataFrame API for Singdata Lakehouse — you write data processing logic in a pandas-like syntax, and ZettaPark automatically tr...
- [ZettaPark Quick Start](https://singdata.com/documents/zettapark-quick-start): A quick start for ZettaPark, covering installation, establishing a session, querying data with DataFrames, and writing to a table within ten minutes.
- [Zettapark DataFrame API Guide](https://singdata.com/documents/zettapark-dataframe-guide): A guide to the Zettapark Python DataFrame API, covering session creation, DataFrame creation, transformations, aggregations, joins, set operations, null handling, window functions, and table I/O.
- [Zettapark Common Functions Reference](https://singdata.com/documents/zettapark-functions-guide): Reference for common functions in the ZettaPark functions module, covering string and other function categories with import setup and runnable DataFrame examples.
- [Zettapark Data Engineering Practice](https://singdata.com/documents/zettapark-etl-guide): Zettapark data engineering practice guide using an order analytics scenario, covering session setup, prerequisite tables, and a multi-table join with aggregation and result-writing example.
- [Zettapark Volume and File Operations](https://singdata.com/documents/zettapark-volume-guide): Guide to Zettapark Volume file operations, covering upload, download, list, delete, reading CSV/Parquet/JSON, and exporting DataFrames, with Named versus External Volume capability comparison and REFRESH notes.
- [Zettapark Table Stream Consumption](https://singdata.com/documents/zettapark-stream-guide): Guide to reading Table Streams as DataFrames in Zettapark for CDC incremental processing, covering session setup, creating source tables with change tracking, and building incremental ETL pipelines.
- [Zettapark Dynamic Table Creation](https://singdata.com/documents/zettapark-dynamic-table-guide): A guide to creating dynamic tables from a DataFrame with Zettapark, covering prerequisites, defining transformation logic, and creating dynamic tables with automatic incremental refresh.
- [Zettapark Feature Engineering](https://singdata.com/documents/zettapark-feature-engineering): A guide to feature engineering with Zettapark, which translates DataFrame operations into SQL for in-Lakehouse distributed execution to build structured feature tables from large-scale user behavior data.
- [Credit Scoring with Zettapark and Python ML](https://singdata.com/documents/credit-scoring-with-zettapark): A step-by-step tutorial building an end-to-end credit scoring machine learning pipeline using Zettapark for Python with scikit-learn, pandas, and seaborn.
