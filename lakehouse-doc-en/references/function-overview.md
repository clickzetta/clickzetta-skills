# Functions

Singdata Lakehouse supports built-in SQL functions and user-defined functions (UDF).

| Type | Description | Reference |
|------|------|---------|
| Built-in SQL Functions | Aggregation, string, datetime, math, and other functions | [SQL Functions](functions.md) |
| SQL UDF | User-defined functions written in SQL | [CREATE SQL FUNCTION](create-sql-function.md) |
| External Function | Functions that call external services (Python/Java) | [External Function](RemoteFunction-intro.md) |
