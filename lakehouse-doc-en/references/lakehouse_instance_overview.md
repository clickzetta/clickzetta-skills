# Lakehouse Service Instance Homepage

Welcome to the Lakehouse service instance homepage. Here, you can quickly learn about our core product capabilities, view the workspaces you have joined, and easily access various functional scenarios. Below is a detailed usage guide:

## How to Enter the Service Instance Homepage

After logging into the Singdata Management Center interface, click the Lakehouse service instance button, and the system will automatically enter the Lakehouse instance homepage.

![](.topwrite/assets/image_1739969731243.png =805)

^

Here, you can find various functional entrances to quickly start your development and operations work.

![](.topwrite/assets/image_1739969804937.png)

### User Instance Information

In this area, you can view your login name, instance ID, current selected cloud service provider, and region information. This helps you understand your current operating environment.

### Core Functional Area

We provide the following quick entrances for you to quickly enter the relevant functional modules:

* Upload Data: Click to pop up the web visual upload data capability, which supports you to quickly upload local files to the Singdata Lakehouse system. For more data upload operations, refer to [Using the Data Upload Function to Upload Data](upload_data.md)
* Sync Data: Singdata Lakehouse also provides various data synchronization capabilities, supporting you to stably and efficiently synchronize different types of data sources to the Singdata Lakehouse system.
* Query SQL: Click to enter the data development module, where you can operate and define periodic tasks, data analysis, and use it in conjunction with operations monitoring capabilities.
* Manage Cluster: Click to enter the cluster management page of Singdata Lakehouse.

### Data Asset Information

* Data Storage: In this area, you can view the total number of objects stored under the current instance and the total storage volume, helping you understand the data scale.
* Compute Usage: View the daily compute usage of the current instance for the past 7 days, so you can allocate resources reasonably.

Note: Data asset information is only available to instance administrator roles.

### Help Documentation

Click here to enter the Singdata Lakehouse product help documentation platform to learn more about product features and operation guides.

### Recent Operations Area

This area displays the 10 tasks and data you have recently accessed. Click to quickly enter the corresponding task or data operation page.
