## V1.0 Release Notes

**Release Date**: February 5, 2026
**Release Scope**: Simultaneous release across Alibaba Cloud Shanghai and AWS Singapore regions

## Core Features Released

**Release Scope**:

1. Standardized unified API gateway: Full compatibility with the OpenAI interface protocol. Business systems built on OpenAI can integrate without any code changes.
2. Initial mainstream model integration: Integration of ByteDance Doubao, Alibaba Cloud Qwen, DeepSeek, and other commonly used large language models.
3. Basic key management: Full lifecycle management for single-platform model API keys, including binding, enabling, and disabling.
4. Basic routing and scheduling: Support for manually specifying model call providers and load balancing across multiple providers.
5. Basic monitoring and statistics: Visual dashboard for real-time key metrics including call volume and call success rate.
