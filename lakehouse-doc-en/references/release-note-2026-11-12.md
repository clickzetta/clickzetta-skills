# Release Notes 2026-11-12

This release introduces new features and enhancements. Updates will roll out gradually to the regions below and are expected to complete within one to two weeks of the release date, depending on your region.

* **China Region**

  * Alibaba Cloud (Shanghai)

* **International Region**

  * Alibaba Cloud (Singapore)
  * AWS (Singapore)

## New Features

* [Answer Explainability](datagpt-answer-explainability-guide.md): View the analysis process, metric definitions, and cited sources to understand and verify analysis results.
* [Analysis Report Generation](datagpt-report-generation-guide.md): Generate PPT presentations or HTML reports using natural language and materials from conversations and dashboards, then preview, revise, and download them.
* [AI Insight](datagpt-AI-insight.md): Generate insights from dashboards and charts using preset or custom analysis approaches, and subscribe to scheduled business briefings.
* [Column-Level Permissions](column_level_permisson—列级权限.md): Control access to sensitive columns through role-based allowlists when departments and users share data tables.

* [AI Guardrail](datagpt-ai-guardrail-guide.md): Uses Amazon Bedrock Guardrails to check user input, final answers, external content, and tool results against configurable safety policies, with protection tests and audit logs to review results.

## Improvements

* [Analytics Agent Interface Upgrade](datagpt-interface-upgrade-guide.md):
  * Reorganized page layouts, consolidated common tools such as file uploads and memory settings, and simplified navigation for finding past conversations and managing analytics domains.
* [Dashboard Editing](datagpt-dashboard-guide.md):
  * Use ASK AI to edit selected charts, create chart filters and adjust filter conditions with natural language, and customize dashboard layouts and styles through page and component settings.
* [Dashboard Version Management](dashboard-version-management-guide.md):
  * Supports edit locks, saved drafts, and explicit publishing; drafts do not affect published content and remain available after you exit editing, while publishing creates a new version that you can preview or use as the starting point for further edits.
* [Account and Personal Settings](datagpt-user-settings-guide.md):
  * Separates tenant-level account configuration from personal language, display mode, and menu settings, making it easier to manage shared defaults and individual preferences.
