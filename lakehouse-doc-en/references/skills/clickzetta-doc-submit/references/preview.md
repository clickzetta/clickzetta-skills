# 本地 Markdown 预览

HTML 页面与 Python 启动器随 skill 分发，渲染器使用 `markdown-it-py`，代码高亮使用 `Pygments`（依赖见 requirements.txt），无 CDN、无 Node 服务、无需联网。只读文档，兼容转换仅发生在内存中，不改动原文件、图片或 Git 状态。首次依赖安装见 SKILL.md；已有个人虚拟环境时使用其中的 Python。

## Agent 打开指定文档

```bash
python3 <skill>/scripts/preview_docs.py <文档绝对路径>
```

根目录自动向上查找 `SUMMARY.md` 或 `.topwrite/`。旧中文/英文仓库以及新 Gerrit 的语言子目录都适用。脚本打印真实 `http://127.0.0.1:<端口>/<会话>/…` 地址并打开默认浏览器；一个文档目录复用一个服务。若工具环境不能打开 GUI，添加 `--no-open` 取得 URL，再用可用的浏览器工具打开或返回链接供用户点击。用户说“预览”仅授权预览，不意味着提交文档。

同名文件有多个时先确定准确路径，不能随意选择另一语言的页面。路径和用户名不硬编码在共享包中。仅预览无需 Gerrit 凭据。

## 手动使用

macOS 双击 skill 目录的 `preview.command`，选择包含帮助文档的文件夹；浏览器随后打开。可搜索文件名、选择左侧文档，或把该目录中的 Markdown 拖入页面。`打开文档` 按钮也可选择文件。若从 ZIP 解压后命令无执行权限，运行 `chmod u+x <skill>/preview.command`，或直接使用 Python 入口。

浏览器不会提供拖入文件的完整路径。工具根据文件名及内容在已绑定目录内定位；若无法匹配、存在同名歧义或文件来自其他目录，页面会提示重新指定路径，不猜测图片根目录。只拖 MD 即可，无需拖入全部图片。图片仍在原文档目录中读取。

无指定文件、只打开文档目录：

```bash
python3 <skill>/scripts/preview_docs.py --root <文档目录>
```

`刷新` 重新读取当前磁盘文件；勾选 `自动刷新` 后可边在编辑器修改、边查看效果。拖入文件时使用拖入内容，自动刷新默认关闭。页面右侧提供章节跳转，Markdown 文档之间的相对链接可在预览器中打开。点击 `阅读模式` 可收起左右侧栏；窄屏下通过左上角 `文档列表` 按钮选择文件。

关闭浏览器标签不会停止后台服务。可重复打开复用；要停止时：

```bash
python3 <skill>/scripts/preview_docs.py --root <相同文档目录> --stop
```

会话状态及日志位于个人目录 `~/.cache/clickzetta-doc-submit/preview/`。升级渲染工具后，下次启动会根据文件版本指纹替换旧服务。

## 兼容范围

| 内容 | 行为 |
| --- | --- |
| 标准 Markdown、表格、删除线、代码块 | 正常解析；SQL / Python 等代码本地语法高亮；未知语言保留转义后的原文 |
| 正文字体与排版 | 对齐官网浅色主题：14px / 28px 正文、32 / 24 / 20 / 16px 标题、蓝色链接与提示框、满宽斑马纹表格 |
| 未指定尺寸的 Markdown 图片 | 与官网一致，铺满正文宽度；保留 SVG / GIF 原始资源 |
| HTML 表格、颜色、内联样式、标签 | 保留 HTML 展示，文档位于隔离的阅读区域 |
| `![](path =640)`、`=50%`、`=640x480` | 设置图片尺寸，最大宽度不超出窗口 |
| `:-: ![](...)`、独立一行 `:-:` | 居中本段；独立标记作用于下一段 |
| 单独一行 `^` | 作为段落分隔，不显示符号 |
| 相对路径、`/.topwrite/assets/...`、旧书根路径 | 按文档位置或最近的文档根目录读取本地资源 |
| SVG、GIF | 使用原始图像资源，保留浏览器支持的动画 |
| 缺图、目录外资源 | 页面给出提示，不下载替换或改写文档 |

主题依据 `https://www.yunqi.tech/documents/object_model_design` 的实际浅色页面样式本地实现，包含正文栏宽度、图片间距、表格、引用提示框与代码配色。使用同一窗口宽度和相同侧栏 / 阅读模式对照，避免因可用正文宽度不同而产生换行差异；官网样式后续变化时需要重新校准。

HTML 表格的 rowspan / colspan、颜色、对齐、字号和内联 CSS 原样保留。字体优先使用官网相同字体，未安装的字体由本机字体回退；不随工具分发官网字体文件。代码高亮使用 Pygments，与官网 CodeMirror 的分词、编辑器交互不保证逐像素一致。Mermaid、TopWrite 专用交互插件、JavaScript 脚本、iframe 嵌入不执行；Mermaid 仍显示代码。外部 URL 图片需要联网，本地图片和渲染本身离线可用。

服务只监听回环地址，带随机会话路径，仅允许访问所选文档目录内的 Markdown、图片和指定附件；不会提供 `.git` 元数据或目录外文件。HTML 样式保留，但文档 JavaScript 不执行。

## 维护验证

```bash
python3 -m unittest discover -s <skill>/tests -v
node --test <skill>/tests/test_preview_ui.cjs
```

Python 测试覆盖渲染、路径解析、HTTP 与启动复用，前端事件测试覆盖页内跳转和拖入文件。Node 仅维护测试需要，使用预览工具不需要 Node。

人工视觉回归可打开 `tests/fixtures/site-preview.md`：包含 HTML 合并单元格、内联颜色 / 字号、SVG 动画、默认满宽 / 固定宽度 / 百分比图片、TopWrite 居中、引用、列表及代码高亮。再用实际文档与官网同页对照，检查正文、图片和表格尺寸及相对位置。
