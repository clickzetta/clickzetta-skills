# Singdata Lakehouse Product Overview

Singdata Lakehouse is an innovative Lakehouse architecture service that fundamentally transforms enterprise data management through a fully managed, unified Lakehouse architecture. Singdata Lakehouse is not a simple extension of traditional database technology or "big data" software platforms. It is built from scratch on a cloud-native design philosophy and comes with a brand-new SQL compute engine. This architecture gives Singdata Lakehouse all the capabilities of an enterprise-grade Data Lake and Data Warehouse, along with many special features and unique advantages.

By seamlessly integrating key components such as Data Warehouse, Data Lake exploration, real-time and batch data processing, and business intelligence reporting, Singdata Lakehouse meets enterprise needs for dynamic scalability, cost control, and performance optimization at every stage of growth. We focus on storage-compute separation and Serverless elastic computing, combined with AI optimization tools, which greatly simplifies data development and management workflows. This not only helps customers gain insights faster and more efficiently, but also fully unlocks the potential of data with unparalleled flexibility and ease of use.

Singdata Lakehouse leverages storage-compute separation and Serverless elastic compute technology, along with intelligent optimization features, to simplify data development and management, accelerating enterprise data insights and value realization.

## Key Product Characteristics

### Truly Fully Managed Cloud Data Platform Service

Singdata Lakehouse is a truly fully managed cloud service, which means:

* You do not need to select, install, configure, or manage any hardware — whether virtual or physical — none of it is your concern.
* In practice, you also do not need to install, configure, or manage any software. We take care of everything.
* All routine maintenance, management, upgrades, and performance tuning are handled meticulously by the Singdata Lakehouse professional team on your behalf.
* Singdata Lakehouse runs entirely on cloud infrastructure. Every component of our service (except optional command-line clients, drivers, and connectors) is hosted in a public cloud environment.
* For compute needs, Singdata Lakehouse uses virtual compute instances; for persistent data storage, it relies on dedicated storage services.
* Unlike traditional software packages, Singdata Lakehouse is not software you install yourself. We handle all software installation and updates to ensure a seamless and worry-free experience for users.

### Next-Generation SQL Data Processing Engine

The SQL data processing engine powering Singdata Lakehouse handles batch processing, real-time computing, and online analytics simultaneously. Without relying on multiple components, users can efficiently process and analyze data through a single engine, significantly reducing the complexity of data application development and accelerating time to value.

The engine is based on a cloud-native architecture, adopting a storage-compute separation model and a vectorized execution engine to ensure leading performance at equivalent resource scales, outperforming mainstream industry products on TPCDS 10TB / TPCH 100GB / SSB 100GB benchmark sets.

### Serverless Elastic Architecture

Singdata Lakehouse adopts a storage-compute separated Virtual Cluster design, providing dedicated execution engines for ETL and analytics workloads to achieve compute optimization. Users can create different virtual clusters based on business needs to achieve workload isolation and meet varying requirements for high throughput and high performance.

The platform intelligently senses business workloads and automatically manages cluster start/stop and elastic concurrency, achieving both low cost and high service-level agreement (SLA) targets.

:-: ![](.topwrite/assets/image_1691805470858.png =712)

### Open, No Data Lock-in

The storage layer of Singdata Lakehouse is compatible with mainstream open storage formats, and the metadata service is provided in Catalog form, allowing external engines to access data files after authentication and authorization. Under a unified security policy framework, the platform delivers optimal openness and, through a rich open-source ecosystem, helps enterprises unlock greater data value.

:-: ![](.topwrite/assets/image_1691805492197.png =664)

### Unified Data Assets

Singdata Lakehouse supports Table-based storage for structured data and file and directory storage for unstructured data. The platform provides fine-grained permission controls based on access control lists (ACL), ensuring unified management and secure access to data assets. In addition, the platform supports exploration and analysis of unstructured data, further improving data utilization efficiency.

:-: ![](.topwrite/assets/image_1691805420547.png =640)

### Integrated Solution for Data Development and Management

Singdata Lakehouse seamlessly integrates the capabilities of the data processing engine with platform tools, providing users with a unified web experience. The platform covers data integration, development and operations, data catalog, security governance, data analytics, and system administration — all in one place. Through storage-compute separation, on-demand elastic virtual clusters, and automated operations and optimization features, it simplifies infrastructure operations and management, offering users a SaaS-based, all-in-one data platform solution.
