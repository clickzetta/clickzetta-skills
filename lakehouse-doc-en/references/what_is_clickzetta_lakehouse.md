## Main Product Features

### A True Self-managed Data Platform Service

Singdata Lakehouse stands out as a genuine self-managed service, which means:

* There’s no need to select, install, configure, or manage any hardware, whether virtual or physical.
* Practically, there’s no software installation, configuration, or management required on your part.
* All ongoing maintenance, management, upgrades, and tuning are expertly handled by the Singdata Lakehouse team.
* Singdata Lakehouse operates entirely within cloud infrastructure. Every component of our service (with the exception of optional command line clients, drivers, and connectors) is hosted in public cloud environments.
* For compute needs, Singdata Lakehouse leverages virtual compute instances, and for persistent data storage, it utilizes a dedicated storage service.
* Unlike packaged software offerings, Singdata Lakehouse is not something you install. We take care of all aspects of software installation and updates, ensuring a seamless and hassle-free experience for our users.

### Next-Generation SQL Data Processing Engine

Singdata Lakehouse is equipped with a robust SQL data processing engine designed to handle batch processing, real-time computing, and online analysis all at once. Users can streamline their data processing and analysis tasks with a single, powerful engine, eliminating the need for complex component integration. This approach dramatically simplifies the development of data applications and speeds up the realization of value.

Built on a cloud-native architecture, this engine leverages a storage-compute separation model and a vectorized execution engine to deliver top-tier performance. It outperforms leading competitors in benchmark tests, including the TPCDS 10TB, TPCH 100GB, and SSB 100GB test suites, even when using the same scale of resources.

### Serverless Elastic Architecture

Singdata Lakehouse utilizes a virtual computing cluster architecture with a decoupled storage and compute layer, offering a specialized execution engine tailored for ETL and analytical tasks to optimize computing performance. Users can dynamically provision virtual clusters based on specific business needs, ensuring business-specific isolation and accommodating varying demands for high throughput and performance.

The platform proactively monitors business workloads, automating the management of cluster lifecycles and elastic concurrency. This intelligent approach not only maintains a high service level agreement (SLA) but also achieves cost efficiency.

### Open and No Data Lock-In

Singdata Lakehouse's storage layer is designed to be compatible with popular open storage formats. It offers a metadata service through a Catalog, enabling external engines to access data files following a secure authentication and authorization process. Within a cohesive security policy framework, the platform ensures optimal openness. Leveraging a robust open-source ecosystem, it empowers enterprises to unlock greater value from their data.

### Unified Data Assets

Singdata Lakehouse accommodates both structured data, stored as tables, and unstructured data, including files and directories. The platform offers nuanced permission management through access control lists (ACLs), guaranteeing centralized governance and secure data asset access. Moreover, it facilitates the exploration and analysis of unstructured data, thereby enhancing the overall efficiency of data utilization.

Singdata Lakehouse harmoniously blends the power of its data processing engine with its platform tools, delivering a cohesive web-based user experience. The platform encompasses a wide range of functionalities, including data integration, development and operations, data cataloging, security governance, data analytics, and system management.
