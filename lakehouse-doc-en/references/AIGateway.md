# AI Gateway

Singdata AI Gateway is an enterprise-grade AI gateway service that provides unified multi-model API management, intelligent routing, BYOK model integration, and usage statistics. It helps enterprises simplify multi-vendor LLM integration so that a single onboarding gives you access to all models.

## Core Capabilities at a Glance

**Unified access**: Call mainstream models from Alibaba Cloud Bailian, ByteDance Doubao, AWS Bedrock, and others through a single API endpoint. 100% compatible with the OpenAI interface format — existing code only needs the endpoint and key replaced.

**Intelligent routing**: Automatically selects the optimal model by price, latency, and throughput, with automatic failover support.

**BYOK**: Bring your own third-party API Key. Billing goes through your own vendor account; the platform charges no additional fees.

**Usage control**: Track token consumption by API Key, team, or project dimension, with support for limits and alerts.
