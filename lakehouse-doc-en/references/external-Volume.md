# Creation and Use of External Volume Objects:

After creating a storage connection, you can create external Volume objects and access object storage data through them.

### Usage Restrictions:

* The current Volume's target object storage supports: Alibaba Cloud OSS, Tencent Cloud COS, Amazon Cloud S3, and Google Cloud GCS.
* Downloading files from an external Volume will incur download fees for the object storage of the associated cloud account. For specific charges, please refer to the cloud provider's object storage billing instructions.
