# Lakehouse LLMs Index Generator

## Overview

`llms.txt` and `llms-full.txt` are LLM navigation index files for the Singdata Lakehouse documentation, generated from `SUMMARY.md`. Both files are hosted at `git@k.topthink.com:4v2dmg3x2e/k7pl9zonpy.git`, local path: `/Users/guanyangw/工作/AI_CODE_COLLECTIONS/lakehouse/clickzetta-documents/`.

## Difference Between the Two Files

| File | Content Scope | Structure |
|------|---------|------|
| `llms.txt` | Only top-level sections (`##`) and first-level sub-pages (`*` direct children, depth=0) | Flat, no indentation |
| `llms-full.txt` | All pages at all levels in SUMMARY.md | 2-space indentation to represent hierarchy |

Both files use the same format:
```
- [Title](URL): one-sentence summary (30-50 words)
```

## URL Generation Rules

**Strictly concatenate based on filename (including directory path), preserving original case:**

```
Remove .md suffix from filename → append to https://www.singdata.com/documents/
```

Examples:
- `overview.md` → `https://www.singdata.com/documents/overview`
- `LakehouseStudio-tour.md` → `https://www.singdata.com/documents/LakehouseStudio-tour`
- `eco_integration/sqlworkbench-j-lakehouse.md` → `https://www.singdata.com/documents/eco_integration/sqlworkbench-j-lakehouse`
- `sql_functions/aggregate_functions/avg.md` → `https://www.singdata.com/documents/sql_functions/aggregate_functions/avg`

> ⚠️ **Note:** Do not perform any case conversion, camelCasing, or path simplification — preserve the original file path exactly.

## Summary Source

Summaries are generated by reading the content of the corresponding `.md` file, 30-50 words, describing the core content of the document. Existing summaries are reused directly; new summaries are only generated for newly added entries.

## Generation Steps

### Step 1: Parse SUMMARY.md

```python
import re

with open('SUMMARY.md', 'r') as f:
    lines = f.readlines()

BASE_URL = "https://www.singdata.com/documents/"

entries = []  # (type, title, url, filepath, depth)
for line in lines:
    # Section headings
    section = re.match(r'^## (.+)', line)
    if section:
        entries.append(('section', section.group(1).strip(), None, None, -1))
        continue
    # List items: number of indent spaces / 4 = depth
    item = re.match(r'^(\s*)\* \[(.+?)\]\((.+?)\)', line)
    if item:
        depth = len(item.group(1)) // 4
        title = item.group(2).strip()
        filepath = item.group(3).strip()
        url = BASE_URL + filepath[:-3]  # remove .md, preserve original path and case
        entries.append(('item', title, url, filepath, depth))
```

### Step 2: Reuse Existing Summaries

```python
with open('llms-full.txt', 'r') as f:
    existing_txt = f.read()

existing = {}
for line in existing_txt.split('\n'):
    m = re.match(r'\s*- \[.+?\]\((https://[^)]+)\): (.+)', line)
    if m:
        existing[m.group(1)] = m.group(2)
```

### Step 3: Generate Summaries for New Entries

For entries where `url not in existing`, read the first 100 lines of the corresponding `.md` file and generate a 30-50 word summary.

### Step 4: Generate llms-full.txt

All entries, following SUMMARY.md hierarchy, with sub-items indented by 2 spaces × depth:

```python
indent = "  " * depth
line = f"{indent}- [{title}]({url}): {summary}"
```

### Step 5: Generate llms.txt

Keep only:
- `##` section headings (formatted as `## Section Name`)
- depth=0 top-level pages (`*` direct children, no indentation)

## URL Validation

Check whether URLs in `llms-full.txt` are consistent with the current SUMMARY.md:

```python
# Extract all valid URLs from SUMMARY.md
valid_urls = {BASE_URL + f[:-3] for _, _, _, f, _ in entries if f}

# Extract all URLs from llms-full.txt
used_urls = set(re.findall(r'https://www\.singdata\.com/documents/[^\)]+', full_txt))

# Find issues
stale = used_urls - valid_urls      # in llms-full.txt but not in SUMMARY.md (old paths/deleted)
missing = valid_urls - used_urls    # in SUMMARY.md but not in llms-full.txt (new pages)
```

Common issues:
- Old format for `eco_integration/` subdirectory entries (missing path prefix) → update to include full path
- New pages added to SUMMARY.md not yet synced to llms-full.txt
