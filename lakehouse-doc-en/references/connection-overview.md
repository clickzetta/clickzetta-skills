# Connection Object

A Connection object stores authentication credentials for third-party services, allowing Lakehouse to access external data without exposing credentials in plaintext.

| Type | Purpose | Reference |
|------|------|---------|
| API Connection | Connect to external API services (AI models, etc.) | [Create API Connection](create-api-connection.md) |
| Storage Connection | Connect to object storage (OSS/COS/S3) | [Create Storage Connection](create-storage-connection.md) |
| Catalog Connection | Connect to external data catalogs (Hive, etc.) | [Create Catalog Connection](create-catalog-connection.md) |

For detailed Connection SQL commands, see [Connection SQL Reference](CONNECTION.md).
