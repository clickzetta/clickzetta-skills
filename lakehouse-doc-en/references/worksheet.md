# Worksheet

## Overview

The worksheet manages or operates all task information under the current instance in the form of a list. In the worksheet, you can quickly and easily locate recently opened projects, and it supports users to create new tasks or perform batch operations on tasks within the workspace.

## Interface Overview

![](.topwrite/assets/image_1740136859124.png)

* Recently Opened: In this tab, the last 10 records recently used in the current workspace are displayed, helping users quickly locate recently opened task nodes.
* Mine: Lists the tasks for which I am responsible in the current workspace.
* All: A list of all tasks in the current workspace.
