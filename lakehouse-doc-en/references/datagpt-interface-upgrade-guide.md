## Usage Tips

* Before asking a question, confirm that the correct analytics domain is selected in the upper-right corner.

* If you cannot find a past conversation, check the selected analytics domain and history type filter.

* To upload files, use web search, or manage memory settings, click **+** to the left of the input box.

* To create an analytics domain or change account settings, open **Management** in the left navigation.

* To expand the main content area, collapse the left navigation. The system remembers your choice.

This update focuses on interface layouts and feature entry points. The core workflow of asking questions and analyzing data using natural language remains the same.
